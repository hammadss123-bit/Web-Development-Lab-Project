# Personal Portfolio Website - Web Development Lab Project

## Project Overview
A responsive personal portfolio website developed as part of the Web Development Lab requirements at the University of Ha'il[cite: 4, 5]. The website dynamically retrieves and displays personal and project information from a MySQL database using PHP[cite: 4, 5].

## Technologies Used
- HTML5 & CSS3 (Responsive Design)[cite: 4, 5]
- JavaScript (Interactive features)[cite: 4, 5]
- PHP
- MySQL Database[cite: 4, 5]

## Features
- Fully responsive layout for desktop and mobile screens.
- Dynamic content loading from MySQL database[cite: 5].
- Interactive JavaScript features[cite: 5].
- Complete sections including Navigation, Home, About Me, Skills, Projects, and Contact Form[cite: 4, 5].
